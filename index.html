    Landmark file

    Saved as .lmk.json with the template, the mesh’s SHA-256 and every point. When you open one, the app checks it belongs to the open mesh. You can also drop a mesh and its landmark file on the page together.

    TPS export

    Rows follow the template order (LM3= blocks, one per specimen, with ID=). Coordinates are in mesh units, unaligned. To combine, choose several saved landmark files made with the same template.
